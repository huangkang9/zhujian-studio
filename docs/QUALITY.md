# 筑间：品质检查与迭代记录

目标：以 Awwwards、Webby Awards、FWA 等数字作品奖项为设计与工程参照。这里不声明获奖，也不以自评分数代替真实评审。

## 第一轮：问题审查

- 视觉：字号过小、辅助文字对比偏低，工具图标不一致，缺少清晰的项目入口。
- 功能：只有一个自动保存项目；缺少矩形房间、量距和草图线条候选提取。
- 几何：修改矩形墙长会使相邻墙体倾斜，正交户型缺少基本约束。
- 交互：手机屏幕被固定属性栏挤压；核心工具键盘可达性不完整。
- 性能：三维静止时仍持续渲染；需要减少闲置 GPU 工作和尊重减少动态效果偏好。
- 验证：已有单元与 DOM 检查，但缺少当前环境可执行的真实浏览器 WebGL 验收。

## 本轮交付门槛

1. 上传/校准 → 编辑尺寸 → 添加门窗家具 → 保存/恢复 → 导出流程可执行。
2. 没有伪造 AI 结果、未连接按钮、虚构奖项或自评获奖分数。
3. 旧版 JSON 和自动保存可迁移，多项目互不覆盖。
4. 窗户截断、门扇角度、尺寸约束与导出回归检查通过。
5. 主界面文字采用可读字号，键盘焦点可见，小屏可收起属性面板。
6. 本地算法和精确尺寸分开：候选线需确认；未识别的标注不虚构。
7. 阻塞项如真实浏览器验收、跨设备体验与完整 AI 识别必须明确记录。

- 完整手绘语义识别（手写尺寸、门窗、房间用途）未接入；本地候选线不可冒充完整 AI。
- 暂无多层、复杂 BIM、曲墙、完整 CAD 约束、固定比例专业图框与施工图审查。
